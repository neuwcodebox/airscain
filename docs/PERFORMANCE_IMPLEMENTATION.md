# 난전 최적화 구현과 검증

기준 분석은 [2026-09-10 측정](PERFORMANCE_2026-09-10.md), 검토할 기법은 [최적화 후보](PERFORMANCE_OPTIMIZATION.md)다. 아래는 실제 구현·측정 결과이며 제외 실험의 예상 감소율을 적용한 수치가 아니다.

## 기관포 공간 후보 검색

`GunfireRuntime`은 각 적분 단계에서 표적 위치를 64m 3차원 격자에 넣고, 탄 이동 구간에 신관 반경·최대 표적 이동 거리를 더한 영역만 조회한다. 표적이 64개 이하거나 조회할 칸이 표적 수보다 많으면 전수 검사를 사용한다. 후보를 원래 등록 순서로 정렬해 동률 피해 순서를 유지하고 기존 상대 선분·안전시간·표면 충돌 판정을 적용한다. 비행탄 없이 폭발 잔상만 남았을 때에는 표적 자료를 수집하지 않는다.

격자는 탄별로 만들지 않고 해당 적분 단계의 모든 탄이 공유한다. 현재는 포대 사이에 장기 캐시하지 않는다. 앞선 무기·피해 신호에서 일어나는 생성·제거와 다음 적분 단계의 위치·속도 변화를 기존 시점 그대로 읽기 위한 범위다. 전역 공유에는 이 변경들의 명시적 무효화 계약이 추가로 필요하다.

### 동일 부하 비교

기준 게임은 `f598d16`의 독립 작업 트리다. Godot 4.7.2, 동일 WSL 환경의 headless/Dummy, 기존 seed 73129의 400 × 50ms 고정 공습을 단독 실행했다. 대형 기준은 독립 세 번이며 마지막 기준은 최종 수정 두 번의 측정 뒤에 재실행했다. 기본 부하는 각각 한 번이다. 격자 구축·조회·정렬 비용을 모두 포함한다.

| CPU 구간 | 기준 | 공간 검색 적용 |
| --- | ---: | ---: |
| 대형 평균, 기준 3회 / 수정 2회 | 50.903 / 54.288 / 51.121ms | 48.932 / 48.347ms |
| 대형 p95 | 108.028 / 108.481 / 106.175ms | 102.511 / 101.676ms |
| 대형 최대 | 158.410 / 165.672 / 161.186ms | 153.631 / 151.327ms |
| 기본 평균 / p95 | 8.346 / 15.069ms | 8.150 / 14.178ms |
| 별도 상세 계측의 기관포 탄도 | 7.763ms | 5.108ms |

대형 평균의 실행 간 평균은 **52.104→48.640ms, 약 6.6% 감소**다. 기관포 탄도 단독은 약 34.2% 줄었으나 한 번씩의 상세 계측이고 전체 게임 시간에 포함된다. 이 수치는 화면 FPS나 렌더 개선율이 아니다. 기본 부하의 작은 차이는 단일 실행이므로 확정적인 개선율로 일반화하지 않는다.

모든 대형 비교의 최대 접촉 364·항적 303·기관포 탄 158, 최종 접촉 206·항적 143·도시 기능 8520은 동일하다. 기본 비교도 최대 접촉 186·항적 120·기관포 탄 53, 최종 접촉 110·항적 38·도시 기능 9250이 동일하다. 발사체 부모의 자식 수에는 실제 프레임 시간에 따른 잔상 수가 포함되어 대형에서 157–161로 달랐다. 이를 비행탄의 불일치로 보거나 전체 시각 상태의 동일성으로 해석하지 않는다.

12개 기관포·60개 표적의 별도 전용 부하는 기준 평균 1.175/1.204ms, 수정 1.245/1.262ms로 **약 0.06ms 증가**했다. 이 부하는 전수 경로를 사용하며 snapshot·조회 호출의 추가 비용이 남는다. 모든 부하에서 빨라지는 변경으로 보고하지 않는다. 대형 혼합 공습의 반복 개선과 이 작은 절대 비용을 함께 고려해 채택했다.

### 규칙 검증

전수 검색을 사용하는 테스트 런타임과 공간 검색 런타임에 같은 seed 3개, 표적 100개·탄 100발, 이동·생성·제거·가변 delta를 넣어 단계마다 생존 탄 상태, 피해, 폭발 위치·원인·순서를 대조한다. 음수 격자 경계의 교차와 동률, 초고속 진입, 신관 안전시간, 건물 최초 접점, 사격 중단·일시정지·저장 복원도 회귀로 확인한다.

관련 기관포·표적 선택·저장 복원 회귀 105개 / 20,649개 단언이 통과했다.

원본 측정 행은 [PERFORMANCE_IMPLEMENTATION.json](PERFORMANCE_IMPLEMENTATION.json)에 보존한다. 재현 명령은 기존 진단기의 기본/`--large`와 `--large --breakdown --detail`이다. 나머지 우선 후보의 구현과 렌더 비교는 진행 중이다.
