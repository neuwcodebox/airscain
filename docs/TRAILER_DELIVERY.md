# Airscain 출시 트레일러 제작·검수 기록

2026-09-26. 영상·음향 편집과 기술 검수는 완료했다. **실제 청감 검수와
처음 보는 관객의 이해도 검증은 미실행**이므로 전체 출시 품질 승인까지
완료했다고 표시하지 않는다. 미적 결정은 제작자가 맡았으며 사용자에게
구도·음악·타이포그래피 선택을 요청하지 않았다.

## 최종 편집

| 시점 | 내용 |
|---|---|
| 0–3초 | 소수 표적과 도시, 실제 첫 교전 |
| 3–7초 | 탐색 레이더 선택·배치·지형 탐지 범위 |
| 7–10초 | 지휘통제소 선택과 실제 연결, 교전 |
| 10–18초 | 중거리 미사일과 기관포의 발사·격추 |
| 18–24초 | 후기 작전의 44개 자산과 대규모 공습 |
| 24–25.5초 | 고고도 레이더, 추적 정보와 지휘 연결 |
| 25.5–39초 | 장·중·단거리 미사일, 레이저, 마이크로파, 요격드론, 기관포 |
| 39–41초 | 실제 탄약 소모 후 유료 재보급 중인 지원망 |
| 41–44초 | 레이더 디코이·무장 디코이가 실제 적 공격을 유인하고 소모됨 |
| 44–50초 | 1.25→1→0.75→0.5초로 짧아지는 무장 교차 컷 |
| 50–53초 | 공습이 계속되는 가운데 실제 도시 피격·기능 저하 |
| 53–55초 | “이 도시에는 당신이 필요합니다.” |
| 55–60초 | AIRSCAIN / “지금 플레이하세요”, 배경 전투 지속 |

모든 등록 방공 자산 13종을 포함한다. 실제 성능·탄약·피해·탐지·경제를
변경하지 않고 유한 예산 배치와 공격 일정을 촬영용으로 구성했다.
연속 플레이 한 판으로 오인하도록 기록하지 않는다. 무장 첫 발사와 실제
피격 시점을 JSON 이벤트 및 연속 프레임으로 확인해 컷을 선택했다.
최종 정확한 소스 in-point는 `edit/*/timeline.json`이 기준이다.

## 검증 결과

- 세 파일 모두 MP4/H.264/AAC, 1920×1080, 60 fps, 3,600프레임,
  60.000초, stereo 48 kHz이며 전체 디코딩을 통과했다.
- 한국어/문구 없는 판: −15.86 LUFS, −1.47 dBTP.
  영어판: −15.89 LUFS, −1.48 dBTP. AAC 출력 파일에서 다시 측정했다.
- 의도하지 않은 검은 구간 및 본편 0–53초의 정지 구간 검출 없음.
  어둡게 처리한 엔딩에서 발생한 임계치 기반 정지 검출은 4 fps 표본
  28/28개 프레임이 서로 달라 실제 정지가 아님을 별도 확인했다.
- 모든 컷의 640×360 축소 프레임과 실제 1080p 렌더를 확인했다.
  초반 2 fps, 몽타주 8 fps, 마지막 피격 4 fps의 연속 프레임을 검토했다.
  장거리 포대 잘림, 설명 문구와 UI 겹침, 디코이 소모 이후 빈 장면을 수정했다.
- 실제 Godot 창에서 촬영, GDScript 구문 확인, Python 구문 확인,
  새 파일 추가 후 Godot import 완료. 게임 동작 오류는 없었다.
  격리 계정의 인증서 저장소 경고는 오프라인 촬영과 무관하다.
- 음악 및 효과음 출처를 기록했다. 출처가 확인되지 않은 접근 비행
  녹음은 제외했다. 음악 크레디트는 엔딩과 게시용 문서에 포함했다.

## 남은 검수 경계

음악의 정서적 적합성, 효과음 피로감, 스피커·헤드폰의 실제 밸런스를
들어서 판정했다고 주장할 수 없다. 측정 통과는 이 항목을 대체하지 않는다.
또한 사전 설명 없는 외부 관객 테스트를 수행하지 않았다. 영상 파일과
기술 자료는 제공하되 이 두 항목은 미검증으로 유지한다. 공개 업로드는 하지 않았다.
