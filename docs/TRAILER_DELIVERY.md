# Airscain 트레일러 제작·검수 기록

## 2차 — 이야기 흐름 재촬영

2026-09-26. 2차 촬영·편집과 시각·기술 검수를 마쳤다. 결과는 `build/trailer_v2/`에
저장했으며 아래 1차 파일은 채택하지 않는다. 실제 청감 검수는 미실행이므로
전체 출시 품질을 수치 검사만으로 승인하지 않는다.

### 구성과 제작 방식

작은 방어망의 성공에서 시작해 훨씬 큰 공습과 도시 앞 교전으로 이어진다.
레이더·포대별 소개 목록, 디코이 전용 장면과 이전 교전의 재사용을 없앴다.

| 영상 시점 | 실제 장면 |
|---|---|
| 0–16초 | 레이더 없는 초기 상태 → 구매·설치 → 탐지 → 첫 격추. 한 테이크. |
| 16–18초 | 같은 해안의 확장된 방어선과 먼 바다. 후기 작전으로 시간 생략. |
| 18–26초 | 저고도 UAV와 고고도 항공기가 여러 겹으로 접근. 교전 전. |
| 26–38초 | 여러 구역의 방어선이 대응하고 새 위협이 계속 접근. |
| 38–44초 | 지면 6m·8m 카메라에서 전경 장비, 중경 자산, 하늘의 교전. |
| 44–50초 | 1.5 → 1.25 → 1 → 0.75초로 짧아지는 같은 공습의 다음 사건들. |
| 50–53초 | 도시 건물을 다시 전경에 두고 아직 진행 중인 교전. |
| 53–60초 | 같은 전투 위에 지휘 요청 2초, 로고와 플레이 유도 5초. |

초반 16초와 후반 44초를 별도로 촬영한다. 후반은 한 시뮬레이션의 카메라만
바뀌며, 편집 시 원본 시간을 생략·반복·역행하지 않는다. 적 100기를 촬영 전에
배치하고 정상 속도로 접근시킨다. 이후 적 항공기의 정상 무장 투하는 게임 사건이다.
영상 제작 코드가 촬영 중 새 공격 기체를 생성하는 경로는 금지한다.

전투 성능이나 게임 규칙을 변경하지 않았다. 방어 자산은 실제 배치 API와 유한
지원 예산으로 설치한다. 후기 작전의 단계와 경제 상태를 연출한 촬영 세션이며,
처음부터 끝까지 사용자가 조작한 무편집 플레이를 주장하지 않는다.

### 시각 검수

초반 한국어·영어 실제 창에서 설치 전후와 첫 요격을 확인했다. 후반 첫 촬영의
포대 내부에 걸친 카메라와 나무가 가린 구도는 채택하지 않고 다시 배치했다.
수정한 실제 교전에서 전경 기관포·포대, 중경 방어선과 하늘의 항공기·궤적을
확인했다. 최종 본편의 컷별 대표 화면과 각 경계 전후 0.12초 표본도 검토했다.
기체의 화면 내 생성은 촬영 코드의 금지 경로와 사전 생성 기록을 함께 확인했다.

검사 도구는 초반 레이더 설치 순서, 기존 자산 ID·위치 유지, 사전 기체 생성,
10초 이상 교전 없는 공습 접근, 끝나지 않은 전투, 정확히 한 번씩 사용하는 원본
프레임을 확인했다. 레이더 설치는 5.5초, 첫 격추는 14.23초이며 후반 첫 발사는
영상 26.4초다. 사전 배치 기체 100기, 후반 종료 시 도시 내구도 50과 남은 위협이
기록되어 있다. 모든 채택 원본 프레임은 정확히 한 번씩 시간 순으로 사용했다.

### 최종 파일 검사 결과

세 MP4 모두 H.264/AAC, 1920×1080, 60fps, 3,600프레임, 60.000초,
48kHz 스테레오다. 전체 디코딩과 연속성 검사를 통과했다.

| 파일 | 통합 음량 | 트루 피크 |
|---|---:|---:|
| `Airscain_Launch_Trailer_KO.mp4` | −15.23 LUFS | −1.47 dBTP |
| `Airscain_Launch_Trailer_EN.mp4` | −15.34 LUFS | −1.48 dBTP |
| `Airscain_Launch_Trailer_KO_CLEAN.mp4` | −15.23 LUFS | −1.47 dBTP |

검은 화면 구간은 검출되지 않았다. 전역 변화량 기반 정지 검출기는 18–20초의
작은 원거리 기체와 53초 이후 어두운 배경을 정지로 분류했다. 별도 검사에서
18–22초의 240프레임이 모두 다르고, 해당 구간의 100기 모두 매초 실제 위치가
달라지는 것을 확인했다. 마지막 7초도 4fps 표본 28개가 모두 달랐다. 이 검출
기록은 삭제하지 않고 `qa/*/technical-report.json`과 디코딩 로그에 보존했다.

### 납품과 검증 경계

한·영 본편, 마케팅 문구 없는 본편, 본편 40초의 실제 게임 썸네일,
게임 효과음·음악 분리 트랙, 촬영 기록과 제작 소스 해시를 같은 출력 폴더에
모았다. 재생성 코드는 저장소 `tools/trailer/`에 있으며 명령은 README를 따른다.
이용 기록과 게시용 음악 크레디트는 `tools/trailer/ASSETS.md`를 따른다.

실제 청감과 외부 관객의 이해도 검증은 수행하지 않았다. 음량·피크·디코딩
검사는 청취 결과를 대신하지 않으며, 해당 검증을 통과했다고 기록하지 않는다.
공개 업로드는 수행하지 않는다.

## 검증 결과

- 세 파일 모두 MP4/H.264/AAC, 1920×1080, 60 fps, 3,600프레임,
  60.000초, stereo 48 kHz이며 전체 디코딩을 통과했다.
- 한국어/문구 없는 판: −15.86 LUFS, −1.47 dBTP.
  영어판: −15.89 LUFS, −1.48 dBTP. AAC 출력 파일에서 다시 측정했다.
- 의도하지 않은 검은 구간 및 본편 0–53초의 정지 구간 검출 없음.
  어둡게 처리한 엔딩에서 발생한 임계치 기반 정지 검출은 4 fps 표본
  28/28개 프레임이 서로 달라 실제 정지가 아님을 별도 확인했다.
- 모든 컷의 640×360 축소 프레임과 실제 1080p 렌더를 확인했다.
  초반 2 fps, 몽타주 8 fps, 마지막 피격 4 fps의 연속 프레임을 검토했다.
  장거리 포대 잘림, 설명 문구와 UI 겹침, 디코이 소모 이후 빈 장면을 수정했다.
- 실제 Godot 창에서 촬영, GDScript 구문 확인, Python 구문 확인,
  새 파일 추가 후 Godot import 완료. 게임 동작 오류는 없었다.
  격리 계정의 인증서 저장소 경고는 오프라인 촬영과 무관하다.
- 음악 및 효과음 출처를 기록했다. 출처가 확인되지 않은 접근 비행
  녹음은 제외했다. 음악 크레디트는 엔딩과 게시용 문서에 포함했다.

## 남은 검수 경계

음악의 정서적 적합성, 효과음 피로감, 스피커·헤드폰의 실제 밸런스를
들어서 판정했다고 주장할 수 없다. 측정 통과는 이 항목을 대체하지 않는다.
또한 사전 설명 없는 외부 관객 테스트를 수행하지 않았다. 영상 파일과
기술 자료는 제공하되 이 두 항목은 미검증으로 유지한다. 공개 업로드는 하지 않았다.
