# VOC.md

실제 플레이 테스트 중에 얻은 피드백을 정리한 문서입니다. 각각 필요시 SPEC.md 및 TECH.md에 업데이트 후 해결하시고 완료 표기하세요.

- [x] 절차적으로 생성한 음향들 듣기가 너무 안 좋습니다. 적절한 프리소스 음원들을 인터넷에서 찾아서 교체하거나, 그 전까지 꺼두세요.
- [x] 메인 메뉴 화면, 게임 플레이 화면, Esc 메뉴 정도의 구성은 필요합니다. 훈련, 샌드박스 모드 같은 건 플레이 화면이 아니라 메인 메뉴에서 선택해야 정상 플레이 도중 훈련이나 샌드박스 모드로 변경이 안 되죠.
- [x] 훈련 시나리오가 부실합니다. 현재 구현상 실제로 플레이어가 알아야 하는 것들을 차근차근 알려주는 시나리오가 필요합니다.
- [x] 종종 적 물체가 도시 허공에 멈춰 있거나 하는데 버그인가요?
- [x] 탐지된 물체를 클릭하라고 하던데 클릭이 안됩니다.
- [x] 허공을 클릭하면 다른 선택되었던 거 해제할 수 있게 해주세요.
- [x] 기본 창 사이즈가 너무 작습니다.
- [x] 3D 에셋이 없기 때문에 기본 도형을 쓰고 로우 폴리로 하는 건 의도에 맞는데, 그래서 VFX에 훨씬 더 공을 들여야 합니다. 훨씬 더 다양한 효과가 있어야 하고 각 효과도 더 품질이 좋아야 합니다. 대충 만들면 안 됩니다. 미사일 연기, 섬광, 폭발 같은 거 지금도 있는 거 같긴 한데 거의 안 보입니다.
- [x] 포대 동작도 마찬가지입니다. 조준하는 과정 없이 즉각 회전되어 발사해버리네요. 기관포도 뭔 레이저처럼 날아가고 있어서 이상하게 보입니다. C-RAM 같은 거 보면 무수히 많은 총알이 날아가잖아요?
- [x] 화면에 안 떠서 뭔진 모르겠는데 아마 크루즈 미사일인가? 비행을 이상하게 해요. 목표에 닿아도 안 터지는 거 같고요.
- [ ] 훈련에서 기본적으로 켜져있는 사격중지가 UI에서는 꺼져있는 거처럼 보임. 이어서 재보급 요청을 누르라는데 비활성화 상태임. 훈련 설계가 좀 치밀하지 못한 거 같네요. 훈련이니 적 물체 하나가 어디서 날아올지는 알려줘야 미사일 포대 적절한 곳에 배치하죠. 그리고 재생 중 상태인데 훈련이니 적절한 시점에 일시정지/재생 자동으로 해줘야죠.
