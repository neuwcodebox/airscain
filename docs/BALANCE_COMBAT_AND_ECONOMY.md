# 타격·전자전·대응탄·유지보수 조정

승인된 구현 계획. 목표는 완성된 방공망에도 관측 기반 제압과 유지보수 선택이 필요하게 만드는 것이다. 첫 공습 종료 후 45초 정비, 적의 관측 정보 제한, 전투 효과의 웹 사전 준비를 유지한다.

## 구현 순서와 기준

1. 타격기의 투발 거리를 도시/포대/레이더/지휘시설 각각 470/380/470/500m로 조정한다. 이전 650/520/650/700m로 전부 되돌리지 않는다. 투발 후 고도·수직 속도·자세의 불연속을 제거하며 전방 지형을 미리 회피한다. 미사일 공격과 충돌 임무의 종말 기동은 구분한다.
2. 관측된 자산이 있는 중반 공습에서 제압 편성 기회를 약 35% 확보한다. 정찰 재시도와 유효 간섭 위치의 전자전 체공을 지원하고 본대 교전 시각에 간섭이 겹치게 한다. 동일 자산에 진행 중인 제압 임무가 과도하게 중복되지 않도록 한다. 미관측 자산·실제 잔탄·C2 그래프를 편성 입력으로 사용하지 않는다. 전자전 반경의 추가 확대와 공습 예산 10~15% 증가는 측정 후 필요할 때만 적용한다.
3. 대응탄 방출·소모와 유도 교란 성공을 분리한다. 거리와 접근 시간을 함께 사용하고 기체 단위 방출 간격으로 순간 중복 소모를 제한한다. 유도 특성에 맞는 플레어/채프를 사용한다. 교란 성공 후 기만 위치 추적·재포착과 기체 회피를 연결한다. 플레어는 움직이는 밝은 연소점과 가는 옅은 연기 궤적으로 표현하고, 실패한 방출도 실제 화면에 보여야 한다. 일시정지·저장 복원과 웹 예열을 검증한다.
4. 수리는 출동비와 구매가·복구량 비례 비용, 피해 정도별 작업 시간을 사용한다. 정상 지원기지 단독 작업 기준 경미 손상 6~10초, 반파 15~25초, 기능 정지 30~45초를 목표로 한다. 수리 중 추가 피해는 이미 결제한 복구량에 포함하지 않는다. 보급·수리의 기존 작업 슬롯 공유와 지원 범위 제한을 유지한다.
5. 보급비/구매가를 아래 값으로 조정한다. 초기 예산·정기 지원금·격추 보상은 우선 유지한다. 고정 조건의 10~15분 비교에서 적의 투발/자산 피해, 재밍과 대응탄 효과, 유지비와 잔액을 보고 추가 수입 감소 여부를 결정한다. 난이도를 올렸다는 이유로 실제 생존률·재밍 효과를 측정 없이 주장하지 않는다.

## 검증

각 단위에서 관련 GUT 회귀와 저장 호환성을 확인하고 실행 가능한 체크포인트로 커밋한다. 타격기 기동과 플레어는 실제 창에서 검증한다. 단일 요격탄 및 동시 요격탄에서 방출 실패/성공/재포착/자원 소모를 구분한다. 동일 seed·배치·시간의 고정 방어 벤치마크를 남기며 이는 인간 숙련도별 난이도 검증과 구분한다. 마지막에 SPEC/TECH/PLAN을 구현과 일치시킨다.
