# Airscain 출시 트레일러 — 6차 화면 구성

실제 게임의 배치·탐지·사격·피해 규칙을 사용한다. 연출용 작전이며 하나의 플레이 세션을 기록했다고 주장하지 않는다. 이전 영상은 보존한다.

| 구간 | 화면과 의도 |
|---|---|
| 0–12초 | 레이더·미사일·기관포 설치, 첫 요격. 실제 전술 아이콘과 초반 탐지음. 마케팅 문구 없이 조작과 결과를 보여준다. |
| 12–18초 | 카메라를 고정한 채 방어선이 17→29→41개로 세 단계 확장된다. 증설 단계 사이만 짧은 페이드. |
| 18–26초 | 마지막 확장 구도에서 끊김 없이 바다 쪽으로 이동·줌. 이미 멀리서 날아오는 편대를 자연스럽게 발견한다. 공습 공개에 페이드를 쓰지 않는다. |
| 26–52초 | 중거리 대응, 겹치는 요격 궤적, 가까운 혼합 교전, 낮은 포대 시점. 각 장면 6.5초로 실제 대응을 따라갈 시간을 준다. |
| 52–54.5초 | 같은 공습 속 탄도미사일 뒤쪽에서 도시를 내려다본다. 재진입과 낙하를 연속 노출하며 처음부터 점멸하지 않는다. |
| 54.5–59초 | 직격 직전에 전장 시간을 감속한다. 화면 노출 66→48→36→27→21→15→12프레임과 암전 9→8→7→6→5→4→3프레임으로 일곱 번 점멸한다. 미사일은 계속 움직이며 탄착 전 절단한다. |
| 59–59.6초 | 암전, 음향 정리. |
| 59.6–61.6초 | “당신의 지휘를 기다립니다.” / “AWAITING YOUR COMMAND.” |
| 61.6–66.6초 | AIRSCAIN / 실시간 방공 전략 / 지금 플레이하세요. 음원 크레딧. |

문구 원칙: 초반과 확장에는 설명·명령형 카피를 넣지 않는다. 마지막 호출 한 줄과 게임명·장르·플레이 안내만 남긴다. 접근 경고 자막과 사이렌은 없다. BGM은 일정한 게인으로 유지한다.

검수: 고정 카메라와 이동 시작 위치 일치, 페이드 없는 공습 발견, 늘어난 전투의 실제 사격, 탄도미사일 가시성과 지붕까지 남은 거리, 감속 중 시간 진행, 가속 점멸, 탄착 미노출을 실제 창 및 최종 출력에서 확인한다.
