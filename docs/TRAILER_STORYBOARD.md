# Airscain 출시 트레일러 화면 구성 — 2차 콘티

상태: 사용자 영상 피드백을 반영한 재설계. **이번 변경은 화면 구성 문서이며 재촬영·재편집은 아직 수행하지 않았다.** 기존 MP4는 연속성·화면 내 생성·나열식 구성 문제로 공개용 채택에서 제외한다. 기존 기술 검사 통과는 연출 합격의 근거가 아니다. 아래 구성이 이전 콘티와 자산별 출연표를 대체한다.

## 중심 구성

**내가 만든 작은 방어망이 작동한다 → 멀리서 훨씬 큰 공습이 온다 → 방어선 전체가 대응한다 → 위협이 방어선 안으로 밀려든다 → 당신의 지휘가 필요하다.**

60초, 16:9, 1920×1080·60fps. 초반 0–16초는 하나의 연속된 소규모 플레이, 18–53초는 하나의 연속된 대규모 공습이다. 16–18초만 후기 작전으로 시간을 생략한다. 개별 무기 소개 목록이나 모든 자산 출연 할당표를 두지 않는다. 다양성은 같은 전장 안에서 서로 다른 방어가 함께 작동하는 모습으로 전달한다.

- 디코이 유인·소모 전용 컷과 해당 카피는 삭제한다.
- 레이더·지원시설·포대를 하나씩 소개하는 후반 전용 컷을 삭제한다. 초반 레이더 배치는 플레이어의 행동을 설명하므로 유지한다.
- 무기별 소개를 한 차례 돌린 뒤 같은 무기 순서를 반복하는 구성을 삭제한다.
- 여러 방공 자산은 혼합 방어선의 전경·중경·배경에 함께 놓는다. 같은 자산이 다시 보일 수는 있지만 다른 시점의 새 사건이어야 한다. 같은 발사·폭발이나 기존 근접 테이크 재사용은 금지한다.

## 화면별 구성

### 01 · 0–3초 · 아직 채워지지 않은 방어망

실제 플레이의 사선 전술 시점. 도시를 화면 오른쪽 1/3, C2와 미사일 포대를 중앙 아래, 레이더를 놓을 빈 땅을 중앙 왼쪽에 둔다. 왼쪽은 바다와 접근 방향이다. **레이더는 처음부터 없다.** 첫 프레임에 이미 설치된 레이더나 교전 장면을 선행 삽입하지 않는다.

정상 HUD를 유지하고 카메라를 고정한다. 1초 이내에 실제 구매 메뉴를 열고 레이더를 선택한다. 적은 촬영 전부터 멀리 존재하지만 아직 이 구도 밖에 있다. 긴 풍경 감상이나 별도 장비 소개는 넣지 않는다.

### 02 · 3–7초 · 설치가 연결을 만든다

01에서 컷을 끊지 않는다. 빈 땅 위 실제 배치 프리뷰, 유효 위치와 연결 관계, 설치 확정, 예산 변화까지 한 번에 보여준다. 설치 후 모델이 남는 시간을 최소 1초 확보한다. 프리뷰를 여러 위치로 오래 끌지 않는다.

카피는 “방공망을 설계하라.” 한 줄. 선택 패널과 실제 연결선을 가리지 않는 빈 하단에 놓는다. 같은 위치·같은 자산 ID·같은 상태를 유지하며 레이더가 사라지거나 다시 배치되는 편집을 금지한다.

### 03 · 7–12초 · 연결된 방어망이 적을 찾는다

동일 테이크를 계속 사용한다. 필요하면 설치 후 C2를 한 번 선택해 실제 연결을 드러내되 설명 패널을 읽히게 하려고 멈추지 않는다. 촬영 전에 존재하던 소수 UAV가 바다 쪽 화면 경계를 넘어 들어오고, 실제 탐지 결과와 포대 회전이 이어진다.

시선은 새 레이더 → 들어오는 표적 → 포대 방향으로 이동한다. 표적의 실제 탐지가 설치한 레이더와 유효한 C2 관계에서 이루어지는 촬영 조건을 사용한다. 10초 전후 카피를 없앤다. 따로 초기화한 network 장면으로 교체하지 않는다.

### 04 · 12–16초 · 첫 교전의 결과

같은 전술 시점에서 실제 발사와 요격을 함께 담는다. 카메라를 바꾸기보다 미사일이 전장 위를 가로질러 첫 표적에 닿는 동작을 보여준다. 결과를 약 1초 남긴다. 작은 성공은 여기서 한 번만 보여준다.

기관포·레이저 등의 개별 소개로 이어가지 않는다. 이 구간까지 도시, 레이더, C2, 포대의 위치·시간·생존 상태는 모두 연속적이다. 실제 사건이 목표 시간에 맞지 않으면 시작 위치와 촬영 전 진행 시간을 조정해 전체 테이크를 다시 찍는다. 장비를 지우거나 시간을 역행하는 접합으로 맞추지 않는다.

### 05 · 16–18초 · 더 먼 바다로 시선을 넘긴다

첫 요격음의 잔향 위로 먼 접근음을 먼저 연결한다. 짧은 어두운 전환 후 같은 해안의 후기 작전으로 컷한다. 도시 실루엣이나 해안 돌출부를 기준점으로 남긴다. 추가 장비가 생기는 순간은 보여주지 않는다.

다음 공습의 전방을 보는 넓은 사선 구도다. 확장된 방어선 일부는 화면 아래 가장자리에, 먼 바다와 하늘은 위 2/3에 둔다. 이때 이미 난전이 벌어진 화면을 넣지 않는다. 실제 작전 시간·단계도 후기 상태여야 한다.

### 06 · 18–22초 · 먼 수평선의 대규모 편대

바다 쪽에서 **이미 비행 중인 큰 편대**를 먼저 보여준다. 개별 기체 하나를 쫓지 않고, 서로 다른 거리와 높이의 전방·본대·후속 편대가 겹쳐 들어오는 폭을 담는다. 전경의 해안과 작은 방어선이 거리를 설명한다.

폭발·요격 궤적 없이 접근 자체에 4초를 준다. 적이 몇 픽셀짜리 점으로만 보이면 촬영 위치와 화각을 바꾸고 편대의 여러 층이 실루엣으로 읽히게 한다. 위협 수치나 가짜 마커를 늘려 규모를 대신하지 않는다. 별도 설명 카피 없이 접근음과 음악의 긴장으로 연결한다.

### 07 · 22–26초 · 다가오는 규모가 분명해진다

같은 편대의 옆·앞 사선으로 한 번만 컷한다. 왼쪽 먼 곳에서 오른쪽 도시 방향으로 진행하는 화면 방향을 유지한다. 낮은 위협은 바다 가까이, 높은 편대는 하늘 위에 분리된다. 앞쪽 기체가 프레임 경계를 지나고 뒤쪽 본대가 계속 남도록 잡는다.

아직 본격적인 방어 사격은 없다. 접근 구간은 실제 유효 교전 거리 밖에서 확보한다. 현재 장거리 포대의 기본 사거리 1100만을 일괄 기준으로 쓰지 말고 실제 배치·고도·탄종·탐지 조건을 확인한다. 적을 사거리 안에 놓고 무기를 인위적으로 정지시키거나 비행 속도를 줄이지 않는다.

### 08 · 26–32초 · 방어선 전체가 처음 응답한다

해안의 혼합 방어선을 비스듬히 보는 중간 높이의 넓은 화면. 가까운 발사대는 오른쪽 아래, 다른 포대들은 중앙에서 먼 해안까지 이어지고, 적 편대는 왼쪽 위에서 들어온다. 한 포대의 발사에서 다른 위치의 발사로 공간이 연결되고, 궤적이 편대 쪽으로 뻗는다.

개별 포대의 정면 제품 사진처럼 자르지 않는다. 최소 두 거점과 접근 편대의 일부를 같은 프레임에 둔다. 정상 발사 시차를 유지한다. 6초 안에서 넓은 구도와 한 단계 가까운 구도 두 컷까지만 사용한다.

### 09 · 32–38초 · 요격해도 다음 편대가 들어온다

첫 요격으로 전방 몇 기가 떨어지지만 그 뒤 본대는 계속 전진한다. 32–35초는 편대와 요격을 함께 보는 중경, 35–38초는 저공으로 더 가까워진 위협과 복수 방어 자산이 함께 있는 구도다.

이동하는 적과 실제 방어 반응이 컷의 이유다. “다음 무기를 보여줄 차례”라서 컷을 바꾸지 않는다. 레이저·탄막·미사일 등이 함께 읽히는 조합을 고르며, 모든 종류를 채우려는 추가 삽입은 하지 않는다. 새 적이 필요하다면 화면 밖에서 들어오는 후속 편대만 사용한다.

### 10 · 38–44초 · 방어선 내부의 로우 앵글 난전

**기존 40초의 높은 시점과 빽빽한 전술 오버레이는 폐기한다.**

38–41초: 지면에서 약 4–8m 높이로, 가까운 기관포나 발사대의 옆·뒤를 바라본다. 전경 장비는 화면 너비 1/4 이내로 제한한다. 중경에는 다른 방어 자산 두세 개, 배경에는 하늘을 가로지르는 적과 요격 궤적을 둔다. 포신 위로 하늘을 올려다보며 무기와 위협 사이에 빈 하늘을 확보한다.

41–44초: 같은 전선의 조금 옆 위치에서, 머리 위를 통과하는 적과 멀리 보이는 도시 건물·다른 포대를 함께 잡는다. 전경의 사격, 중경의 폭발, 배경의 계속 접근하는 편대가 깊이감을 만든다. 빠른 카메라 회전이나 과장된 흔들림은 쓰지 않는다.

HUD·범위 원·C2 선·항적 마커는 근경에서 숨긴다. 실제 기체·탄·레이저·연기만으로 전투를 읽힌다. 카메라를 지형이나 장비 안에 넣지 않고, 도시·적이 전경 장비에 모두 가려지는 테이크는 버린다. 지원시설 설명 패널을 다시 삽입하지 않는다.

### 11 · 44–50초 · 가까워지는 위험으로 컷을 가속

직전 난전 이후의 새 사건을 이어 붙인다. 같은 발사·격추를 다시 재생하지 않는다. 무기 종류별 순서도 두지 않는다.

| 시점 | 사건과 구도 |
|---|---|
| 44–45.5 | 방어선 너머 본대가 아직 남아 있는 중경. 앞쪽 표적 하나가 떨어지고 뒤의 위협이 공간을 채운다. |
| 45.5–46.75 | 낮은 사선에서 실제 저공 위협이 프레임 위를 가로지르고 지상의 복수 자산이 대응한다. |
| 46.75–47.75 | 가까운 방어 자산의 사격 너머에서 요격. 섬광 뒤에도 접근 기체가 남는다. |
| 47.75–48.5 | 잔해가 카메라 앞을 지나며 그 뒤 다른 궤적이 이어진다. 카메라를 가리는 시간을 길게 두지 않는다. |
| 48.5–49.25 | 방어선/도시 방향의 실제 피격. 공격 접근 방향과 충격 위치가 연결되어야 한다. |
| 49.25–50 | 피격 뒤에도 발사하는 가까운 방어선. 도시 쪽 위협을 남겨 다음 컷과 연결한다. |

이는 사건별 목표 길이다. 실제 촬영에서 해당 사건이 없으면 같은 단계의 새 사건으로 대체하며 가짜 파편·공격·피해를 합성하지 않는다. 실제 섬광과 밝기 차이로 점멸감을 만들고 기본은 하드 컷으로 한다. 인위적 흰 프레임이나 자산별 재소개는 없다.

### 12 · 50–53초 · 지켜야 할 도시가 다시 보인다

도시 가장자리의 낮은 건물 높이에서 바다를 바라본다. 오른쪽 아래 건물 일부, 중앙의 가동 중인 방어선, 왼쪽 위의 계속 접근하는 공습을 함께 둔다. 바로 앞의 실제 피격 연기나 궤적을 앞 컷에서 이어 받는다.

3초 동안 화면을 유지한다. 멀리서 시작했던 위협이 이제 도시 앞에 있다는 공간 변화를 끝까지 전달한다. 적 전멸·방어 성공·패배 화면으로 결말을 닫지 않는다. 52.5초부터 음악과 큰 충격음을 급격히 줄인다.

### 13 · 53–60초 · 당신의 지휘가 필요하다

직전 전장의 시간이 계속 흐르는 상태로 어둡게 처리한다. 새로 평온한 전장이나 앞선 시간의 전경으로 되돌리지 않는다.

53–55초: “이 도시에는 당신이 필요합니다.” / “THIS CITY NEEDS YOU.”

55–60초: AIRSCAIN + “지금 플레이하세요” / “PLAY NOW”. 타이틀은 5초 유지한다. 음악 크레디트는 기존 이용 조건에 맞게 보존한다.

## 생성 노출과 시간 연속성 — 촬영 필수 조건

1. **초반은 하나의 세션·하나의 테이크로 촬영한다.** 시작에는 레이더가 없고 설치 뒤에는 끝까지 남는다. 자산 ID·위치·예산·실제 작전 시각·탐지와 교전 사건을 기록한다.
2. 후반 주 공격 편대는 촬영 전 바깥에서 미리 생성하고 정상 비행으로 접근시킨다. 예열 완료와 적의 출발 위치·방향·간격 안정화를 모두 확인한 뒤 유효 테이크를 시작한다. 녹화 파일 앞부분을 잘라낼 수는 있으나 화면 안에서 적이 생성되는 프레임은 채택하지 않는다.
3. 후속 편대는 촬영 중인 모든 카메라의 시야 밖이면서 다음 카메라에도 갑자기 노출되지 않는 지점에서만 생성한다. 기체 중심뿐 아니라 날개·추진 효과까지 화면 밖에 있어야 한다. 화면 밖 마커가 생성 순간 먼저 튀어나오는지도 확인한다.
4. 바다 안개로 스폰을 가리는 편법에 의존하지 않는다. 실제 모델·궤적이 보이지 않는 위치에서 정상적으로 들어와야 한다. 카메라 이동이나 컷 전환으로 생성 지점이 보일 수 있으므로 전체 카메라 경로를 검사한다.
5. 후반 여러 시점은 동일 교전의 앞으로 진행하는 시각을 사용한다. 가능하면 하나의 시뮬레이션에 카메라 컷 일정을 넣는다. 재현 테이크가 필요하면 표적 ID·위치·발사·명중·도시 상태를 대조한다. 동일 seed만으로 연속성을 보장하지 않는다.
6. 접근 18–26초와 첫 교전 26초 이후의 공간 관계를 먼저 검증한다. 먼 편대가 안개나 렌더 거리 때문에 읽히지 않으면 카메라와 비행 경로를 조정한다. 사거리·속도·가시성을 임의로 바꾸거나 이미 난전인 화면으로 대체하지 않는다.
7. 정상 속도 전투를 사용한다. 44–50초의 속도감은 컷 길이와 사건 밀도로 만든다. 직전 발사·폭발의 시간 역행, 같은 장면 재사용, 갑자기 수가 늘어나는 화면 내 생성은 실패로 판정한다.

## 재촬영 전 확인할 화면

- 초반 단일 테이크: 설치 전 빈 자리 → 설치 → 탐지 → 실제 요격. 기존 장비 소실·상태 초기화가 없어야 한다.
- 접근 테스트: 전투가 시작되기 전에 충분히 큰 편대를 8초 동안 읽을 수 있어야 한다. 이미 뻗은 미사일 궤적과 폭발로 시작하면 실패다.
- 로우 앵글 테스트: 4–8m 높이에서 실제 전경·중경·배경이 분리되고, 기체가 하늘 위에서 읽혀야 한다. 숫자상 적이 많아도 연기와 장비에 가려지면 실패다.
- 연속성 검토: 카메라별 경계 진입 전후·모든 컷 전후를 연속 프레임으로 확인한다. 생성 노출은 대표 한 장의 스크린샷으로 통과시키지 않는다.
- 이 세 대표 테이크와 연속성이 확보된 다음에만 본 촬영과 편집을 진행한다. 기술 인코딩·음량 통과와 연출 통과를 별도로 기록한다.
