# Airscain 출시 트레일러 — 3차 화면 구성

60초. **구축 → 즉각적인 첫 성과 → 확장 → 먼 대규모 공습 → 방어선의 대응 → 돌파 위기 → 지휘 요청.**

초반 12초와 후기 작전 48초는 각각 연속 촬영한다. 후반 첫 14초는 하드 컷 없이 방어선을 따라 이동하다가 원거리 공습으로 다가가며 화각을 좁힌다. 카메라를 모든 순간에 움직이기보다 배치 동작에서는 고정하고, 성과·규모 공개에서는 이동하고, 교전의 새로운 사건에서는 컷한다.

| 시간 | 사건·구도·카메라 |
|---|---|
| 0–2 | 실제 구매 메뉴와 레이더 설치. 도시 오른쪽, 설치 공간 중앙. 이전보다 가까운 전술 시점. |
| 2–4 | 동일 시점에서 미사일 포대 배치. 새 모델·예산 변화·연결을 보여준다. |
| 4–6 | 기관포로 근거리 방어를 보완한다. 설치는 각 한 번이며 장비를 지우지 않는다. |
| 6–10 | 적 접근과 첫 발사·격추. 카메라가 천천히 낮아지며 요격 쪽으로 향한다. 설치 후 긴 정적을 없앤다. |
| 10–12 | 첫 성과의 잔향. HUD를 거두고 다음 장면의 해안·도시 구도까지 자연스럽게 이동한다. |
| 12–18 | 같은 해안의 후기 작전. 직전과 카메라 위치·목표·화각을 맞추고 마지막 프레임을 0.35초 겹쳐 전환한다. 확장된 여러 방어 구역을 따라 전진하며 “방어선을 확장하라.”를 짧게 표시한다. 아직 교전하지 않는다. |
| 18–26 | 직전 이동을 끊지 않고 해안에서 바다 쪽으로 나간다. 실제 카메라 전진과 60→43도 화각 변화로 여러 높이의 편대를 점차 크게 드러낸다. |
| 26–30 | 첫 반격. 방어선 쪽으로 컷하고 여러 포대가 같은 방향을 향해 대응하는 전체 관계를 보여준다. 느린 측면 이동. |
| 30–34 | 전경 발사 궤적·중경 해안·배경 접근 편대를 함께 둔 사선 장면. 요격 속에서도 남은 공습을 보여준다. |
| 34–38 | 방어선 가까이 낮아진 시점. 여러 체계의 동시 대응과 더 가까워진 기체를 함께 담는다. 수목을 전경 주제로 삼지 않는다. |
| 38–41 | 지면 6m, 기관포와 옆 방어 자산 뒤에서 하늘을 향한다. 약한 전진으로 긴장감을 유지한다. |
| 41–44 | 지면 8m, 포대 옆을 따라가며 연속 발사·근거리 대응을 본다. 장비 내부를 통과하지 않는다. |
| 44–50 | 1.5→1.25→1→0.75초의 컷. 전체 교전→측면 포대→레이저·드론 구역→더 가까운 발사→도시 건물 가장자리→마지막 근거리 대응. 서로 다른 현재 사건이며 개별 자산 소개가 아니다. |
| 50–53 | 도시 건물을 전경에 두고 남은 공습과 방어선을 다시 연결한다. 느린 이동을 유지한다. |
| 53–60 | 같은 전장의 시간이 이어지는 배경 위 “이 도시에는 당신이 필요합니다.” 2초, AIRSCAIN / “지금 플레이하세요” 5초. |

## 촬영과 채택 조건

- 초반 세 배치는 실제 선택·프리뷰·설치 API를 사용한다. 설치 실패나 사라진 장비가 있으면 실패다.
- 적은 촬영 전에 미리 배치한다. 후반 대기는 무기 성능 변경 대신 접근 거리로 확보한다. 정상 무장 투하만 게임 사건으로 허용한다.
- 첫 요격은 10초 이내, 마지막 배치에서 첫 발사까지 3초 미만을 목표로 한다. 실제 기록으로 확인한다.
- 중간 장면과 공습 접근의 카메라 위치·화각은 경계에서 연속이다. 이동은 가감속을 주며, 초기 장비 배치에서는 카메라를 고정한다.
- 후기 작전의 첫 교전은 26초 이후다. 다가오는 편대를 보여주기 전에 교전 장면을 끼우지 않는다.
- 카메라 경로 전체의 전경 가림과 지형 관통을 실제 촬영에서 검사한다. 정지 미리보기만으로 통과시키지 않는다.
- 후반 컷은 같은 전투의 앞으로 진행하는 원본 시간을 사용한다. 발사·폭발 재사용이나 시간 역행은 없다.
- 실제 청감은 자동 음량 검사와 구분해 기록한다. 이전 버전의 검사 수치를 새 파일에 재사용하지 않는다.
