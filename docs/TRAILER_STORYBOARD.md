# Airscain 출시 트레일러 촬영 콘티

상태: 촬영 전 설계. 시간과 구도는 편집 목표이며 실제 창에서 촬영 가능성과 가독성을 확인한다. 본 문서가 이전 12컷 구성과 대화에 표시된 배치도를 대체한다. 촬영·영상·음향의 공개 품질 검수는 아직 완료되지 않았다.

## 1. 중심 감정과 구조

**이해 → 작은 성공 → 규모의 반전 → 총력 대응 → 아직 끝나지 않은 위기 → 당신의 개입.**

초반에는 적은 장비와 위협으로 플레이어의 역할을 빠르게 이해시킨다. 18초부터 같은 도시의 확장된 후기 방공망과 대규모 복합 공습을 공개한다. 후반에는 실제 게임의 모든 방공 자산을 각 역할로 등장시키고, 발사·탐지·요격·보급·피격 장면을 짧고 빠르게 교차한다. 도시를 지켰다는 승리로 닫지 않고, 대응하는 것보다 더 많은 위협이 밀려오는 순간 관객에게 지휘를 넘긴다.

- 60초 / 1920×1080 / 60fps / 한국어·영어 각 1종.
- 본편 0–18초는 이해, 18–44초는 규모·다양성·압박, 44–53초는 가속된 위기, 53–60초는 직접적인 초대다.
- 실제 화면에서 자산과 기능을 보여준다. 무기별 이름 카드로 전투를 끊지 않는다. 센서·C2·지원·디코이는 사격 대신 실제 역할을 수행한다.
- 끝 문구: “이 도시에는 당신이 필요합니다.” → `Airscain` → “지금 플레이하세요”. 영어는 “THIS CITY NEEDS YOU.” → `Airscain` → “PLAY NOW”.
- 대규모 장면은 정상 게임 규칙으로 유지 가능한 후기 작전 상태를 사용한다. 모든 자산의 해금·예산·탄약·전력·지원 관계가 유효해야 한다. 무한 예산이나 훈련·자유 모드 전용 UI를 가짜 정상 HUD로 덮지 않는다.

## 2. 전장과 촬영의 공통 규칙

- 전장 후보는 `island_city`, 첫 seed 후보는 `73129`. 실제 생성 결과의 도시·해안·합법 배치점을 보고 확정한다. 밝은 늦은 오후를 유지해 궤적과 무기를 읽게 한다.
- 초반 구도 A: 바다·접근로는 왼쪽 5–35%, 포대·레이더는 중앙 38–65%, 도시는 오른쪽 67–88%. 카메라는 약 35–42도 내려다보며 고정한다.
- 근접 구도 B: 자산은 오른쪽 아래, 사격 대상과 비행 여백은 왼쪽 위. 게임 화면을 좌우 반전하지 않는다.
- 후기 전경 C: 같은 도시와 해안을 더 넓게 담아 기존 거점 밖으로 펼쳐진 방공망을 드러낸다. 도시와 눈에 띄는 지형을 초반의 기준점으로 남긴다. 여러 접근 방향은 이 넓은 샷에서 먼저 소개한다.
- 포화 전경 D: 도시 중앙 뒤, 좌우·상단에서 다축 위협이 들어오는 구도. 중고도 미사일 궤적, 저고도 탄막, 도시 앞 방어를 서로 다른 화면 영역에 둔다.
- 초기 방위는 왼쪽 공격·오른쪽 방어를 유지한다. 후기 다축 공습은 C/D 전경으로 방향을 먼저 설명한 뒤 각 축의 가까운 화면으로 들어간다. 연속 컷의 주 피사체를 비슷한 화면 위치에 두어 빠른 컷에서도 시선을 잃지 않게 한다.
- 18초의 규모 반전은 **같은 도시의 후기 작전으로 시간을 생략한 몽타주 전환**이다. 장비가 몇 초 만에 자동 생성된 것처럼 연속 배치를 위조하지 않는다. 도시의 같은 실루엣을 맞춘 전경 컷과 확대된 방공망으로 시간 경과를 표현한다. 생존 시간·위협 단계 등 실제 HUD는 일관된 게임 상태를 유지한다.
- 각 촬영은 최소 2초 앞뒤 여유를 둔다. 같은 사건의 다른 카메라 테이크는 표적 ID·발사·격추 시점으로 맞춘다. seed만으로 완전 결정성이 보장된다고 가정하지 않는다.
- 설치·탐지·C2·발사·명중·피해·재보급은 실제 runtime 결과다. 불가능한 동시 사격, 합성된 항적, 가짜 과열·피격 표시를 만들지 않는다.

## 3. 컷별 촬영 지시

### S01 · 00:00–00:03 · 이미 벌어지고 있는 공습

- A 구도에서 도시, UAV 2–3개, 기존 미사일 포대를 한 화면에 둔다. 0.5초 전후 실제 발사, 끝부분에 요격 궤적을 보여준다.
- 정상 전술 HUD·마커 유지, 메뉴 닫힘, 카피 없음. 고정 카메라와 실제 발사음으로 바로 시작한다.
- 다음 컷: 같은 도시·포대 위치를 유지하며 레이더 선택으로 연결. 첫 장면만 보고 공중 액션 게임으로 오해하지 않도록 3초에 조작 화면으로 간다.

### S02 · 00:03–00:07 · 내가 방공망을 만든다

- 레이더 구매 선택을 1초 안팎으로 보여주고, 화면 중앙 왼쪽 합법 배치점으로 커서를 옮긴다. 기존 C2에 연결되는 실제 프리뷰 → 확정 → 설치 결과를 남긴다.
- 카메라 정지, 실제 메뉴·가격·예산 변화·배치 힌트 유지. 카피 “방공망을 설계하라.”는 4.5초부터 빈 하단에 나타난다.
- 배치 힌트나 중요한 프리뷰와 카피가 겹치면 카피 등장만 늦춘다. 장비가 클릭 없이 갑자기 나타나는 컷은 쓰지 않는다.

### S03 · 00:07–00:10 · 연결된 방어

- 지휘통제소를 선택해 레이더·포대로 이어지는 실제 청색 C2 선을 보여준다. 레이더/C2/포대 세 노드가 실제 선택창 밖에서 읽히게 카메라를 맞춘다.
- 실제 항적을 관측하는 순간까지 연결한다. “방공망을 설계하라.”는 9.5초 전에 사라진다.
- 선택 자산에 연결된 실제 관계만 표시한다. 선 위로 가짜 데이터 광점을 합성하지 않는다. 새 레이더가 해당 항적 제공자인지 기록한다.

### S04 · 00:10–00:14 · 첫 번째 보상

- 전술 시점의 조준에서 B 구도의 발사 근경으로 컷, 발사에서 실제 요격까지 보여준다. 포대 오른쪽 아래 → 표적 왼쪽 위의 방향을 유지한다.
- 근경은 HUD 숨김, 요격 결과는 실제 전술 화면으로 복귀해도 된다. 발사·명중 사건을 중복 재생하지 않는다.
- 발사음과 첫 요격음에 무게를 두고, 결과를 약 0.5–1초 보여준다. 초반의 작은 성공이다.

### S05 · 00:14–00:18 · 가까운 위협에도 대응한다

- 기존 미사일 포대보다 도시 가까이 놓인 기관포를 한 화면에 보여준다. 고정된 사선에서 UAV를 향한 조준 → 탄막 → 근거리 요격.
- 방어 계층이 다르다는 것을 거리와 화면으로 전달한다. 두 번째 긴 구매 과정을 반복하지 않는다.
- 17초까지 작은 성공을 읽게 하고 17–18초에 음악의 박자를 비우며 다음 전경을 준비한다. 평온한 도시로 쉬어가지 않는다.

### S06 · 00:18–00:24 · 규모가 뒤집히는 순간

- 초반 도시와 실루엣을 맞춘 C 전경으로 하드 컷. 같은 도시 둘레에 확장된 포대·센서·지원 거점과 여러 방향에서 접근하는 공습이 드러난다.
- 18–20초에는 전경을 충분히 유지해 규모를 이해시키고, 20–24초에 원거리 발사와 접근하는 군집·고도별 위협을 읽게 한다. 정상 전술 HUD·고도 프로파일을 활용한다.
- 신규 공습 후보는 UAV 군집·저고도 순항·고속 타격기·탄도 위협. 초기 촬영 부하 후보는 동시 활성 40–80개로 시작하되 고정 요구 수치는 아니다. 실제 작전 규칙·성능·읽히는 규모에 따라 조정하고 실측 수치를 남긴다. 단순히 화면을 몇 개 표적만 보이게 줄여 대규모 요구를 없애지 않는다.
- 19.5–23초 카피: “공습은 멈추지 않는다.” 음악의 저역과 리듬이 본격적으로 들어온다. 이 장면부터 관객의 질문은 ‘어떻게 하는가’에서 ‘이걸 버틸 수 있을까’로 바뀐다.

### S07 · 00:24–00:29 · 먼 하늘까지 열린 전선

- 24–25.5초: 고고도 레이더와 실제 높은 항적·고도 프로파일. 이미 화면에 들어온 탄도/고고도 위협을 읽게 한다.
- 25.5–27.5초: 장거리 포대의 실제 발사. 발사대 오른쪽 아래, 큰 상승 궤적 왼쪽 위. 렌즈 이동보다 발사 자체를 강조한다.
- 27.5–29초: 여러 고도의 접근 궤적과 원거리 요격을 전술 시점으로 묶는다. 모든 표적이 해결되는 장면은 피한다.
- 컷마다 무기 이름을 쓰지 않는다. 관측 → 발사 → 하늘이라는 연결로 기능을 보여준다.

### S08 · 00:29–00:33 · 사방에서 발사되는 요격탄

- 29–31초: 기존 중거리 미사일 포대의 연속 교전. 31–33초: 다른 축에서 들어오는 저고도 위협에 단거리 미사일 대응.
- 각 자산은 2초씩 형태·발사 방향·효과가 보이게 잡는다. 중거리와 단거리를 동일한 장면 확대만으로 대체하지 않는다.
- 원거리 폭발 잔향이 남은 채 가까운 발사음이 이어져 전선이 가까워지는 느낌. 두 장면의 피사체 위치를 오른쪽 아래로 맞춘다.

### S09 · 00:33–00:37 · 에너지 방어도 가동된다

- 33–35초: 레이저 장비와 표적을 한 화면에 담아 실제 조사와 표적 반응을 보여준다. 35–37초: 고출력 마이크로파가 밀집 전자 표적에 실제 작동한다.
- 전력 공급이 유효한 배치와 현재 구현의 VFX를 사용한다. HPM을 존재하지 않는 거대한 충격파로 키우지 않는다.
- 두 자산 모두 본편에서 처음 읽히는 시간이므로 0.3초 삽입으로 처리하지 않는다. 이후 빠른 재등장 컷의 인지 기준이 된다.

### S10 · 00:37–00:41 · 요격드론과 마지막 탄막

- 37–39초: 요격드론 기지에서 실제 출격해 느린 UAV를 향해 접근하는 샷. 적 드론과 구별되도록 출발 거점·실제 아군 표식을 남긴다.
- 39–41초: 도시 앞 기관포의 조준과 밀도 높은 탄막. 뒤편으로 건물과 또 다른 위협이 보인다.
- 드론을 고속·탄도 위협 대응처럼 표현하지 않는다. 이미 형성된 실제 교전의 한 순간을 선택하고 결과를 보기 위해 가짜로 속도를 높이지 않는다.

### S11 · 00:41–00:44 · 버티는 체계와 미끼

- 41–42초: 통합 지원기지와 인접 자산의 실제 보급·수리 진행 표시를 함께 담는다. 공급 역할은 배경의 모델만 스쳐 지나가는 것으로 충족하지 않는다.
- 42–43초: 레이더 디코이가 실제 공격을 끌어받는 테이크. 43–44초: 무장 디코이에 대한 별도 공격·소모 장면. 실제 장비처럼 사격하지 않는다.
- 디코이가 의도한 표적이었는지 적 임무·명중 객체로 확인한다. 촬영에서 이 역할이 1초로 읽히지 않으면 앞선 무장 반복 컷 시간을 줄여 지원/디코이 장면을 늘린다. ‘모든 자산 출연’을 포기하거나 보이지 않는 배경 배치로 대신하지 않는다.
- 음악은 계속 가속하지만 보급 완료나 디코이 폭발마다 별도의 큰 소리를 추가하지 않는다.

### S12 · 00:44–00:50 · 점멸하는 총력 대응

이미 소개한 자산들을 빠르게 재등장시킨다. 아래는 60fps 기준 첫 편집안이다. 각 슬롯의 길이에 짧은 암전 삽입도 포함하므로 러닝타임을 늘리지 않는다.

| 시간 | 프레임 길이 | 화면 |
|---|---:|---|
| 44.00–45.25 | 75 | 고고도 위협을 향해 장거리 포대가 발사. 프레임 중심은 발사 섬광. |
| 45.25–46.25 | 60 | 중거리 포대의 다중 교전. 이전 섬광 위치와 맞춰 하드 컷. |
| 46.25–47.00 | 45 | 저공으로 파고드는 표적을 향한 단거리 요격. |
| 47.00–47.75 | 45 | 레이저가 붙잡은 표적, 뒤에 남아 있는 다른 항적. |
| 47.75–48.50 | 45 | 밀집 군집에 대한 마이크로파 작동. |
| 48.50–49.00 | 30 | 요격드론이 표적에 접근·교전하는 순간. |
| 49.00–49.50 | 30 | 기관포 점사와 도시 앞 탄막. |
| 49.50–50.00 | 30 | 실제 도시/자산 피격과 화면에 남은 공습. |

- 컷 길이를 1.25 → 1 → 0.75 → 0.5초로 좁힌다. 시뮬레이션은 정상 속도이며 속도감은 사건과 컷 길이에서 나온다.
- 점멸감은 실제 포구 섬광·폭발광의 밝기 차이와 하드 컷으로 만든다. 선택한 2–3개 전환에 2프레임의 어두운 간격을 넣어 리듬을 끊을 수 있다. 흰 화면을 반복 삽입하지 않는다. 각 검은 프레임은 편집표에 의도된 구간으로 기록한다.
- 여기서는 자막·설명·메뉴를 넣지 않는다. 모든 자산을 처음 소개하는 구간이 아니라 앞서 본 무장들이 한꺼번에 한계까지 대응한다는 인상을 만든다.
- 음악은 가장 빠른 호흡. 컷마다 소리를 더 크게 쌓기보다 발사·기관포·충격음의 전면을 번갈아 넘긴다.

### S13 · 00:50–00:53 · 그런데, 아직 더 온다
