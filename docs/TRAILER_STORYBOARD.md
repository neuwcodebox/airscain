## 촬영 원칙

게임의 정상 배치·센서·전투·피해·탄도 비행을 사용한다. 서로 다른 시기의 준비된 작전이며 단일 플레이 세션이라고 주장하지 않는다. 배치 자산은 다음 확장 단계와 공습 장면에서 보존한다. 적은 각 테이크 촬영 전에 생성한다. 탄도미사일의 위치나 속도를 카메라용으로 조작하지 않는다. 출처 불명 접근 녹음은 제외한다.

초반은 기존 게임 아이콘을 촬영 화면에 맞게 확대한다. 적 아이콘은 실제 탐지 항적에서만 생성되며 미탐지 표적에 합성 표시하지 않는다. 후반 탐지음은 track-created 오디오 연결만 촬영 세션에서 끊고 다른 전투음을 유지한다. 사이렌은 코드로 합성한 독자 음향이며 실제 게임 기능이라고 표시하지 않는다.

## 검수

설치와 발사 시간, 단계별 자산 증가·보존, 후반 탐지 알림 0건, 100기 사전 생성, 재진입과 하강, 탄착·격추 미노출을 실제 기록으로 검증한다. 최종 파일은 전체 디코드·프레임·음량 검사와 컷별 시각 확인을 한다. 의도된 확장 페이드와 마지막 암전은 검은 화면 오류와 구분한다. 실제 청감 검수 여부는 별도로 기록한다.
