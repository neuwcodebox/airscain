# 구현 계획과 이력

`SPEC.md`의 완료 조건과 `TECH.md`의 기술 경계를 기준으로 한 고수준 작업 체크리스트다. 각 완료 항목은 실행 가능한 상태로 검증한 뒤 해당 변경과 함께 커밋한다.

- [x] 실행 가능한 첫 수직 플레이 루프 구성
  - Godot 4.7.2 Mobile 프로젝트와 영속 입력·메인 장면 설정
  - seed 기반 구릉 지형과 box 도시 생성, 지형과 공유하는 높이·경사 query
  - `ProtectedObjective`, `DefenseUnit`, `ThreatUnit` 역할과 Resource 기반 첫 시나리오
  - 예산 원자성을 갖는 미사일 포대 배치와 배치 preview/사거리/실패 사유
  - UAV 지속 생성·접근·강하, 포대 표적 선택, 실제 유도 요격미사일과 폭발 표현
  - 준비/진행/게임오버, 일시정지·1×·2×, HUD·최종 통계·동일/신규 seed 재시작
  - 검증: `godot --headless --path . --editor --quit`, `godot --headless --path . --quit-after 180`
- [x] 규칙·통합 테스트와 장기 안정성 검증
  - TECH 지정 버전인 GUT 9.7.1을 저장소에 포함
  - seed 결정론, 배치 제한·예산 원자성, 목표 상태, 위협 1회 resolution, 표적 우선순위, 공격 압력 단위 테스트
  - 역할 테스트 대역을 사용해 공통 구매 흐름이 첫 콘텐츠 타입에 결합되지 않았음을 검증
  - 시나리오 초기화, 구매·방어 시작·요격·보상, 임무 피해·게임오버 통합 테스트
  - 10분 고속 플레이 검사에서 생존 600초, 무력화 1,185, 포대 36, 위협 단계 14, 활성 위협 16, 도시 상태 90 확인
  - 검증: GUT 13개 테스트·55개 assertion 통과, `tools/long_run_check.gd` 통과
- [x] 실제 게임 창 시각 검증과 역할 경계 보정
  - 절차 지형 triangle winding을 Godot front-face 규칙에 맞춰 지형 렌더링과 camera ray 배치를 복구
  - 녹색 구릉 지형·청색 환경광·그림자 bias, 원형 사거리 preview와 유효/무효 색상 보정
  - 미사일 발사 섬광 위치를 보정하고 `GPUParticles3D` 연기 궤적 추가
  - 초기·배치·교전·게임오버 화면을 실제 Forward Mobile 게임 창에서 1280×720으로 캡처·확인
  - 구체 발사체 갱신을 미사일 포대 내부로 이동해 공통 `Main`의 첫 콘텐츠 타입 분기 제거
  - 방어 Definition 목록에서 구매 버튼을 동적으로 생성하도록 공통 HUD 보정
  - 카메라 WASD·휠 zoom·중간 버튼 drag 테스트 추가
  - 검증: GUT 17개 테스트·64개 assertion 통과, 600초 재검증(무력화 1,188·활성 위협 13·도시 상태 90), 실제 창 캡처 통과
- [x] SPEC/TECH 완료 조건별 최종 감사와 전체 CLI 검증
  - SPEC 완료 조건 1~16을 전장/seed, 배치 원자성, 지속 전투, 보상·피해 1회성, 압력 증가, 게임오버·재시작, 표현, 장기 안정성, 역할 확장성 증거와 대조
  - 첫 시나리오와 모든 Definition의 필수 참조·값 범위를 실행 전에 검증하고 필수 보호 목표만 게임오버에 반영
  - 공통 `Main`·세션·HUD·director·registry에 첫 콘텐츠 타입 분기가 없음을 정적 검색으로 확인
  - 최종 검증: 프로젝트 전체 로드 및 메인 장면 단기 실행 성공, GUT 19개 테스트·70개 assertion 통과
  - 최종 장기 검증: 생존 600초, 무력화 1,188, 포대 36, 위협 단계 14, 활성 위협 13, 도시 상태 90
  - 최종 재시작 검증: 동일 seed 지형 일치 및 신규 seed·지형 변경 확인
- [x] 저장소 작업 계획·커밋 규칙 정비
  - 비단순 작업은 `docs/PLAN.md`에서 실행 가능한 고수준 단위로 추적
  - 각 단위를 검증한 뒤 구현·테스트·계획 이력을 하나의 일관된 커밋으로 기록
  - 폐기된 접근의 대화 기록이 아니라 현재 의도와 검증된 결과가 남도록 계획 문서 유지
