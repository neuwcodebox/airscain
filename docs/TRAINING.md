# 훈련 시나리오

기준: 현재 실행 코드. 기본 흐름은 배치 → 탐지 → 표적 확인 → 사격 → 전투 후 정비다. 설명은 현재 필요한 행동에 붙이고, 자동 처리 절차는 플레이어에게 지시하지 않는다.

## 진행과 통과 조건

| 단계 | 플레이어 행동 또는 관찰 | 다음 단계 조건 | 시간 |
|---|---|---|---|
| CAMERA | 주황색 진입 방향 확인 | 계속 | 정지 |
| RADAR | 접근로에 저·중고도 레이더 배치 | 해당 레이더 배치 | 정지 |
| WEAPON | 레이더 근처에 미사일 포대 배치 | 포대 배치 | 정지 |
| CONNECT | 연결 실패 때만 강조 자산 재배치 | 레이더에서 지휘시설을 거쳐 포대로 연결 | 정지 |
| ACQUIRE | 접근과 탐지 관찰 | 확인 적성 항적, 확신도 0.3 이상 | 재생 |
| SELECT_TRACK | 강조된 항적 선택 | 같은 공개 항적 조건의 선택 | 정지 |
| ENGAGE | 자동 요격 관찰 | 실습 표적 종료 | 재생 |
| SUPPLY_STATUS | 포대의 재보급 대기 표시 확인 | 계속 | 재생 |
| SUPPORT | 포대 근처에 지원기지 배치 | 포대가 지원 범위 안 | 재생 |
| WAIT_RESUPPLY | 자동 재보급 관찰 | 실제 보급 완료 후 계속 | 재생 |
| REPAIR | 포대 내구도 확인, 수리 요청 | 해당 포대 작업 접수 | 재생 |
| WAIT_REPAIR | 내구도 회복 관찰 | 실제 수리 완료 후 계속 | 재생 |
| CITY_RESTORE | 도시 관리에서 피해 복구 | 실제 예산 지출과 복구 | 재생 |
| COMPLETE | 메인 메뉴로 돌아가 새 게임 | 완료 | 재생 |

연결이 정상인 경우 CONNECT 안내는 바로 넘어간다. 탐지 중 사거리와 고도 조건을 충족한 표적이 지형에 가려질 때만 RELOCATE로 분기한다. 추천 위치는 배치 가능, C2 연결, 표적까지 시야 확보를 검사한다. 실제 재배치 시작 → WAIT_RELOCATE 재생 → 완료 → CONNECT에서 연결 재확인 → ACQUIRE로 이어진다. 이 분기는 탐지 진행도에 포함한다.

보급과 수리가 끝나면 해당 안내 본문을 유지하고 완료 표시와 계속 버튼을 보여준다. 실제 작업 완료와 플레이어 확인을 모두 거쳐 다음 실습으로 진행한다. 전투 후 지원기지 배치부터 도시 복구까지 재생을 유지한다.

## 실습 상태 설정

- 로딩 완료: 도시 동쪽 800m에 일반 비행 속도의 표적을 한 번 생성하고 작전을 시작한 뒤 정지한다.
- 포대 배치: 일반 자산의 기본 자동교전과 자동 재보급 설정을 사용한다.
- 첫 교전 종료: 예비탄을 0으로 설정하고 보급 실습 상황임을 즉시 안내한다.
- 보급 완료 후 계속: 포대 최대 내구도의 25% 손상을 적용하고 수리 실습 상황임을 안내한다.
- 훈련 수리 요청: 비용·범위·복구량과 공통 지원 queue는 유지하고, 정상 지원기지 단독 작업 시간을 최대 3초로 제한한다.
- 수리 완료 후 계속: 도시 복구 1회 분량의 피해를 확보하고 복구 실습 상황임을 안내한다.

지원기지가 없는 포대의 실제 재보급 대기 상태를 확인한 뒤, 지원 범위 안에 기지를 설치한다. SupportManager의 자동 점검이 실제 보급 작업을 접수하고 예산과 보급 규칙을 적용한다.

| CONNECT | 끊긴 연결 복구 | 청색 연결선이 이어지지 않았습니다. 강조된 자산을 선택하고 재배치를 눌러 추천 위치로 옮기세요. |
| ACQUIRE | 접근 감시 | 레이더와 포대가 연결됐습니다. 주황색으로 표시했던 방향에서 표적이 접근 중입니다. 레이더가 항적을 만드는 모습을 관찰하세요. |
| SELECT_TRACK | 탐지된 표적 확인 | 적성 항적이 확인됐습니다. 강조된 항적 표식을 클릭해 표적 정보를 열어보세요. |
| ENGAGE | 요격 관찰 | 표적이 사거리 안에 들어오면 포대가 자동으로 발사합니다. 발사된 미사일과 표적의 움직임을 관찰하세요. |

| SUPPORT | 지원기지 연결 | 방공 자산을 열어 통합 지원기지를 포대 근처에 배치하세요. 포대까지 녹색 지원선이 연결되면 자동으로 재보급을 시작합니다. |
| WAIT_RESUPPLY | 탄약 보충 확인 | 지원기지가 자동으로 예비탄을 보충합니다. 포대 선택 패널의 작업 진행도와 예비탄 수량을 확인하세요. 완료되면 예비탄이 채워집니다. |
| REPAIR | 손상된 포대 수리 | 보급이 완료됐습니다. 다음 정비 실습을 위해 포대에 경미한 손상을 적용했습니다.<br><br>포대를 선택해 내구도를 확인하고 수리 요청을 누르세요. |
| WAIT_REPAIR | 수리 결과 확인 | 지원기지가 포대의 내구도를 회복합니다. 선택 패널에서 수리 결과를 확인하세요. |
| CITY_RESTORE | 도시 피해 복구 | 포대 수리가 완료됐습니다. 마지막으로 도시 복구 실습용 피해를 적용했습니다.<br><br>상단 도시 관리를 열고 피해 복구를 누르세요. 예산을 사용해 도시 내구도를 즉시 회복합니다. |
| COMPLETE | 훈련 완료 | 도시 복구까지 마쳤습니다. 레이더와 포대를 연결해 요격하고, 소모된 탄약과 피해를 복구했습니다.<br><br>Esc 메뉴에서 메인 메뉴로 돌아가 새 게임을 시작하세요. |
| RELOCATE | 탐지 사각 해결 | 표적이 탐지거리 안에 들어왔지만 지형에 가려져 있습니다. 강조된 레이더를 선택하고 재배치를 누른 뒤, 접근로가 트인 추천 위치로 옮기세요. |
| WAIT_RELOCATE | 자산 재설치 | 자산을 옮기고 있습니다. 재설치가 끝나면 연결과 탐지 상태를 다시 확인합니다. |
