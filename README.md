# Airscain

**불완전한 정보 속에서 통합방공망을 구축하고 운용하는 3D 실시간 전략 게임.**

주변 해역이 사실상 봉쇄된 전략적 섬 도시. 플레이어는 장기화된 분쟁 속에서 끊임없이 이어지는 공습에 맞서 통합방공망을 구축하고 도시를 지켜야 합니다.

## Features

* 절차적으로 생성되는 로우 폴리 3D 도시와 주변 전장
* 실제 위협과 방공망이 인식한 항적이 분리되는 불완전한 정보 시스템
* 센서 탐지, 추적, 분류와 IFF
* 센서와 방어체계를 연결하는 지휘통제망
* 미사일, 기관포, 레이저 등 서로 다른 역할을 가진 다층 방공체계
* 탄약, 전력, 손상과 지원 능력을 고려한 장기 운용
* 정찰, 기만, 포화, SEAD와 타격을 조합하는 복합 공습
* 플레이어의 방공망과 이전 교전 결과에 반응하는 적 공격
* 실제 3D 공간에서 이루어지는 요격과 전투 VFX
* 고정된 웨이브가 아닌 지속적인 생존형 작전
* 실제 플레이 흐름을 안내하는 훈련과 자유 조합용 샌드박스

## Gameplay

플레이어는 센서, 지휘통제 수단, 방어체계와 지원시설을 배치하고 제한된 자원을 운용합니다.

센서가 위협을 발견하고 항적을 형성하면 정보가 방공망을 통해 공유되고, 각 방어체계는 자신의 역할과 교전규칙에 따라 자동으로 대응합니다.

적은 시간이 지날수록 단순히 많아지는 것이 아니라 정찰, 기만, 방공망 제압과 다양한 공격수단을 조합하며 방어망의 약점을 파고듭니다.

최종 승리 지점은 없습니다. 도시가 더 이상 기능할 수 없게 될 때까지 방공망을 확장하고 가능한 오래 버티는 것이 목표입니다.

## Technology

* Godot 4.7.2
* typed GDScript
* Procedural low-poly 3D

## Run

Godot 4.7.2가 필요하며 `godot` 명령이 `PATH`에 있어야 합니다. 새로 clone한 저장소에서는 먼저 에디터 메타데이터와 import 결과를 생성합니다.

```bash
godot --headless --audio-driver Dummy --editor --path . --quit
```

최초 초기화가 끝나면 게임을 실행합니다.

```bash
godot --path .
```

`.godot/`은 Git에 포함되지 않으므로 clone한 직후 초기화를 건너뛰면 `class_name` 타입을 찾지 못하는 parse error가 발생할 수 있습니다. Windows PowerShell에서도 같은 명령을 사용합니다.

메인 메뉴에서 지속 작전, 훈련 또는 샌드박스를 선택합니다. 플레이 중 `Esc`를 누르면 일시정지, 저장 또는 메인 메뉴 복귀가 가능합니다. 저장과 불러오기는 지속 작전에서만 제공됩니다.
